<Expandable title="Detailed Migration Guide for v2.0.0" default-open="false">

For OAuth 2.0 migration:

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  const response = await fetch('https://api.runwaysocial.studio/v2/posts', {
    headers: {
      Authorization: `Bearer ${YOUR_ACCESS_TOKEN}`
    }
  });
  ```
  ```python
  import requests
  response = requests.get(
    'https://api.runwaysocial.studio/v2/posts',
    headers={'Authorization': f'Bearer {YOUR_ACCESS_TOKEN}'}
  )
  ```
</CodeGroup>

Replace `YOUR_ACCESS_TOKEN` with your new OAuth token.

</Expandable>
