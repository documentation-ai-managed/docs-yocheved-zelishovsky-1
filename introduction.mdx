## Overview

Runway Social Studio empowers property managers and owners to elevate their multifamily communities' online presence. You create compelling content, schedule posts across platforms, and analyze engagement metrics all in one intuitive dashboard. Specializing in multifamily properties, the platform helps you showcase amenities, share resident stories, and foster community interaction effortlessly.

<Callout kind="info">
Runway Social Studio integrates with major platforms like Instagram, Facebook, and TikTok, tailored for real estate professionals.
</Callout>

## Quick Start

Get up and running in minutes:

<Steps>
  <Step title="Sign Up" icon="user-plus">
    Create your free account at `https://dashboard.example.com/signup`.
  </Step>
  <Step title="Connect Properties" icon="building">
    Add your multifamily communities and link social accounts.
  </Step>
  <Step title="Create First Post" icon="plus">
    
````javascript
// Sample API call to create a post
const response = await fetch('https://api.example.com/v1/posts', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    propertyId: 'prop_123',
    platforms: ['instagram', 'facebook'],
    content: 'Discover our new amenities! #MultifamilyLiving',
    scheduleDate: '2024-10-20T10:00:00Z'
  })
});
````

  </Step>
  <Step title="Monitor Results" icon="eye">
    View engagement in your dashboard.
  </Step>
</Steps>

<CodeGroup tabs="JavaScript,Python">
```javascript
// Embed widget on your property website
const script = document.createElement('script');
script.src = 'https://dashboard.example.com/widget.js';

document.head.appendChild(script);
```

```python
# Python integration example
import requests

response = requests.post(
    'https://api.example.com/v1/posts',
    headers={'Authorization': 'Bearer YOUR_API_KEY'},
    json={
        'propertyId': 'prop_123',
        'content': 'Welcome to our community!'
    }
)
```
